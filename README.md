# Pedidos Distribuidora
App web móvil para levantar pedidos. Administrador (productos, precios, stock, promos, importar Excel, usuarios) y vendedores (cargan y ven solo sus pedidos).

- `npm install && npm start`
- Variables: `APP_USER` / `APP_PASS` (administrador inicial, por defecto kevin / kevin123), `AUTH_SECRET`, `DATABASE_URL` (Postgres; sin esto guarda en `data/pedidos.json`).
